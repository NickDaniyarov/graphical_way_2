📘 Раздел 1

Графический метод решения систем

Цвета прямых одинаковы во всём приложении: красная — первое уравнение, фиолетовая — второе, оранжевая точка — решение.

1

Что такое система и её решение

Определение. Решением системы уравнений с двумя переменными называется пара значений (x; y), которая обращает каждое уравнение системы в верное равенство.

Пример: { y = x + 1 ; y = −x + 3 } → решение (1; 2).

  • График линейного уравнения — прямая линия
  • Каждая точка прямой — решение своего уравнения
  • Точка пересечения прямых принадлежит обеим прямым → это решение системы
💡 Решить систему графически — значит найти координаты точки пересечения графиков.
2

Алгоритм решения

Запомни 5 шагов:
  1. Вырази y через x в каждом уравнении: y = kx + b
  2. Составь таблицу из двух точек для каждой прямой
  3. Построй обе прямые в одной системе координат
  4. Найди точку пересечения, запиши её координаты (x; y)
  5. Проверь подстановкой в оба уравнения
Разбор примера { y = x + 1 ; y = −x + 3 }
  1. Оба уравнения уже в виде y = kx + b.
  2. 1-я прямая: x=0 → y=1; x=2 → y=3. Точки (0;1) и (2;3).
  3. 2-я прямая: x=0 → y=3; x=3 → y=0. Точки (0;3) и (3;0).
  4. Прямые пересекаются в точке (1; 2).
  5. Проверка: 2 = 1 + 1 ✔ и 2 = −1 + 3 ✔

Ответ: x = 1, y = 2.

🧮 Если координаты точки пересечения дробные, график даёт приблизительный ответ. Точный дают способы подстановки и сложения.
3

Три случая: сколько решений?

Пересекаются → 1 решение
k₁ ≠ k₂

Параллельны → нет решений
k₁ = k₂, b₁ ≠ b₂

Совпадают → бесконечно много
k₁ = k₂, b₁ = b₂

СлучайУсловиеПримерОтвет
Пересекаютсяk₁ ≠ k₂y = x + 1; y = −x + 3(1; 2)
Параллельныk₁ = k₂, b₁ ≠ b₂y = 2x + 1; y = 2x − 3решений нет
Совпадаютk₁ = k₂, b₁ = b₂y = 2x + 1; 4x − 2y = −2бесконечно много
⚠️ Одинаковый k — ещё не значит «нет решений»! Обязательно сравни b.
4

Как построить прямую y = kx + b

Прямая строится по двум точкам! Удобнее всего брать x = 0 и x = 2.
  • k — угловой коэффициент (наклон)
  • b — ордината точки пересечения с осью Oy: точка (0; b)
  • k > 0 — прямая идёт вверх ↗
  • k < 0 — прямая идёт вниз ↘
  • k = 0 — прямая горизонтальная →
✅ Лайфхак: если уравнение дано в виде 2x + y = 4, вырази y: y = −2x + 4. Если x − 2y = 6, то y = 0,5x − 3.

⭐ Плюсы и минусы метода

  • + Наглядно видно, что такое решение системы
  • + Сразу понятно, сколько решений
  • − Ответ часто приближённый
  • − Нужны аккуратность и клетчатая бумага

🚫 Частые ошибки

  • Неверно выразили y через x (потеряли знак)
  • Построили только одну прямую
  • Записали ответ как (y; x) — сначала x!
  • Не сделали проверку подстановкой

💡 Подсказки к упр. 3.88

С чего начать

Вырази y через x в каждом уравнении системы. Выпиши по две точки для каждой прямой (удобно x = 0 и x = 2 или x = 4).

Как выбрать масштаб

1 клетка = 1 единица. Если числа большие — 1 клетка = 2 единицы, но обязательно подпиши оси.

Если прямые параллельны

k одинаковые, b разные → «Система решений не имеет».

Если прямые совпали

k и b одинаковые → «Система имеет бесконечно много решений».

🧠 Памятка на дом

  • 2 прямые → точка пересечения → ответ
  • y = kx + b: точка (0; b) + ещё одна точка
  • k > 0 ↗, k < 0 ↘, k = 0 →
  • k₁ ≠ k₂ → одно решение
  • k₁ = k₂, b₁ ≠ b₂ → решений нет
  • k₁ = k₂, b₁ = b₂ → бесконечно много
